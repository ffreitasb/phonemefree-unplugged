# Documentation

Project documentation lives here, grouped by subject.

| Directory | Purpose |
| --- | --- |
| `project/` | Planning, roadmap, release scope, and project management notes. |
| `hardware/` | Public hardware documentation, BoMs, sourcing notes, and assembly references. |
| `firmware/` | Firmware architecture notes, build notes, and implementation references. |
| `legal/` | Licensing model, third-party notices, release compliance, and branding policy. |

Internal/private notes should not live here unless they are intended to be published.
