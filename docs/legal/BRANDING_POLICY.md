# Branding Policy

The open hardware and software licenses in this repository do not grant trademark rights.

This policy exists to keep forks welcome while avoiding confusion about what is official.

## Names And Marks

The following project identifiers are reserved as project branding:

- `PhonemeFree`
- `PhonemeFree Unplugged`
- Project logos, icons, and visual identity assets.

## Allowed Uses

You may use the project name and logo to:

- Refer to the upstream project.
- Link to the upstream project.
- Describe an unmodified copy of the upstream source or firmware.
- State that your work is a fork or derivative of PhonemeFree Unplugged.

## Not Allowed Without Permission

You may not use the project name or branding to:

- Imply that a modified device, firmware build, PCB, or kit is official.
- Imply endorsement by the upstream project.
- Sell a modified product as `PhonemeFree Unplugged` without clear differentiation.
- Use confusingly similar branding for an incompatible fork.

## Fork Naming Guidance

Modified products and forks should use their own names and may include a factual attribution such as:

```text
Based on PhonemeFree Unplugged.
```

or:

```text
Forked from PhonemeFree Unplugged, with modified firmware and hardware.
```

Clear attribution is good. Confusing branding is not.

## Assets

Branding assets in `assets/branding/` are provided so this repository and unmodified redistributions can identify the project. Their presence does not grant permission to present modified products as official.

This document is project guidance, not legal advice.
