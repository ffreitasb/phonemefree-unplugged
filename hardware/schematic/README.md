# Schematic

Conceptual schematic diagrams and future schematic source files live here.

Current files:

| File | Purpose |
| --- | --- |
| `mvp_breadboard_wiring.mmd` | Mermaid wiring diagram for the public MVP breadboard/perfboard build. |
| `future_custom_pcb_blocks.mmd` | Mermaid block diagram for a future custom PCB. |

These diagrams are not a substitute for a KiCad schematic. They are the bridge between the public BoM and the future PCB design.
