# Perfboard Prototype

DIY double-sided perfboard build notes will live here.

Target style:

- 2.54 mm plated-through double-sided perfboard.
- Socketed ESP32-S3 board when possible.
- Replaceable I2S microphone module.
- Short underside wiring for BCLK, WS, DATA, 3V3, and GND.
- Microphone placed near an edge with its acoustic port unobstructed.
