# Breadboard Prototype

Temporary wiring notes for the first hardware proof.

Use this stage for:

- MCU board verification.
- I2S microphone wiring.
- USB enumeration tests.
- Early firmware bring-up.

Keep I2S wires short. If audio behaves strangely, shorten wiring before treating it as a firmware bug.
