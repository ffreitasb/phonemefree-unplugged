# Hardware

Hardware design and assembly material lives here.

| Directory | Purpose |
| --- | --- |
| `schematic/` | Conceptual schematic diagrams and future schematic source files. |
| `breadboard/` | First-pass wiring notes and temporary prototype layouts. |
| `perfboard/` | DIY double-sided perfboard builds after breadboard proof. |
| `pcb/` | Future PCB design sources, usually KiCad projects. |
| `mechanical/` | Enclosure, acoustic port, mounting, and physical integration notes. |
| `manufacturing/` | Future Gerbers, BOM exports, pick-and-place files, and fabrication packages. |

The first public build is expected to start on breadboard, then move to double-sided 2.54 mm perfboard before any custom PCB.
